# Aqara G3 Light Control v1.1.0

Это независимый экспериментальный проект для локального управления RGB-индикатором Aqara Camera Hub G3. Облачное подключение, изменение прошивки и фоновая служба не требуются.

## Возможности

- Команды штатного индикатора `on`, `off` и `status`.
- Семь бинарных RGB-сочетаний: `red`, `green`, `blue`, `yellow`, `cyan`, `magenta`, `white`.
- Временная подсветка на 1–60 секунд с восстановлением предыдущего состояния GPIO.
- Готовый статический ARMv7-бинарник и его исходный код на C.

Произвольные 24-битные цвета и PWM пока не реализованы.

## Требования и распиновка

Нужны Aqara Camera Hub G3, root/Telnet, BusyBox/POSIX `sh`, работающий `ha_agent`, доступные GPIO и чтение `/sys/kernel/debug/gpio`.

Подтверждённая распиновка G3 — active-low:

| Канал | GPIO | Активен при |
| --- | ---: | --- |
| Красный | 49 (`red-gpio`) | `0` (LOW) |
| Зелёный | 6 (`green-gpio`) | `0` (LOW) |
| Синий | 48 (`blue-gpio`) | `0` (LOW) |

Не используйте эти номера на других моделях без проверки имён GPIO ядра.

## Установка

Скачайте `g3-light-v1.1.0.tar.gz`, разместите его на доверенном HTTP-сервере в локальной сети, затем из Telnet G3 под root выполните:

```sh
wget -O /tmp/g3-light.tar.gz http://HA_IP:8123/local/g3-light-v1.1.0.tar.gz
mkdir -p /tmp/g3-light-setup
tar -xzf /tmp/g3-light.tar.gz -C /tmp/g3-light-setup
sh /tmp/g3-light-setup/g3-light/install.sh
```

## Примеры

```sh
/data/bin/g3-light status
/data/bin/g3-light on
/data/bin/g3-light off
/data/bin/g3-light red
/data/bin/g3-light green 3
/data/bin/g3-light white
```

Удаление: `sh /tmp/g3-light-setup/g3-light/uninstall.sh`.

## Предупреждения

Изменение LED может замаскировать штатную индикацию записи, просмотра или приватности. Не используйте проект для сокрытия видеосъёмки или отключения обязательных индикаторов приватности. Проект неофициальный, экспериментальный и не содержит закрытую прошивку Aqara, пароли, токены, приватные IP-адреса или закрытые идентификаторы камеры.

Для восстановления штатной индикации выполните `/data/bin/g3-light on` и при необходимости верните настройку в Aqara Home.
