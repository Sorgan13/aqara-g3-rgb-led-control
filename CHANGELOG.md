# Changelog

## v1.1.0 — 2026-10-11

- Self-contained GitHub-ready distribution with `g3-ledctl-armv7` and its C source.
- `install.sh` automatically installs companion when absent and preserves existing binaries.
- Install-time and runtime checks of kernel GPIO labels prevent accidental use on unknown camera models.
- `uninstall.sh` only removes binaries installed by this project.
- Added documented seven RGB combinations, native on/off, status and timed restoration.
- Added README in Russian and English, hashes and license.

## v1.0.0 — 2026-10-11

- Initial camera-specific installer and RGB status indicator script.
